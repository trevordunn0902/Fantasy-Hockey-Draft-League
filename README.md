A full-stack fantasy hockey application built with React, Spring Boot, and PostgreSQL.

## Features

- League creation and joining
- Live NHL player draft system
- Player filtering by position/team
- Fantasy scoring system
- Automated player statistic updates
- Team roster management

## Tech Stack

Frontend:
- React
- Vite
- CSS

Backend:
- Java Spring Boot
- Maven

Database:
- PostgreSQL

Deployment:
- AWS Elastic Beanstalk
- AWS RDS
- CloudFront
- S3
